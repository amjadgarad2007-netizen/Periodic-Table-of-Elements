# الجدول الدوري للعناصر | Periodic Table of Elements

جدول دوري تفاعلي بالكامل باللغة العربية والإنجليزية — أنقر على أي عنصر لتعرض كل تفاصيله الكيميائية.

Interactive Periodic Table of the Elements — fully bilingual (Arabic / English). Click any element to explore its full chemical details.

## المميزات | Features

- 🔢 **118 عنصراً** كاملين — 118 elements
- ⚛️ **نموذج بور الذري** — رسم تفاعلي لتوزيع الإلكترونات في المستويات (Bohr model)
- 🧲 **التوزيع الإلكتروني** وفق مبدأ أوفباو (Aufbau principle)
- 📦 **صناديق المدارات** مع قاعدة هوند (Hund's rule orbital boxes)
- ⚠️ **تنبيه الشذوذ الإلكتروني** — مثل الكروم والنحاس والذهب (electron configuration anomalies)
- 🔍 **بحث فوري** — بالاسم العربي/الإنجليزي، الرمز، أو العدد الذري (instant search)
- 🎯 **فلترة حسب الفئة** — اضغط على أي فئة في المفتاح لعزل عناصرها (category filter)
- 🎮 **اختبار تفاعلي** — 10 أسئلة عشوائية عن الرموز والأسماء والأعداد والفئات مع النتيجة (quiz game)
- 🌙☀️ **وضع ليلي / نهاري** — يحفظ اختيارك تلقائياً (dark/light theme)
- 🌐 **واجهة عربية / إنجليزية** بالكامل مع تبديل فوري
- 📱 **متجاوب** مع جميع أحجام الشاشات
- 🧩 أرقام المجموعات (1–18) والدورات (1–7) على الجدول نفسه
